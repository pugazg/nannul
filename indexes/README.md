# Indexes

Human-facing navigational indexes for Nannūl belong here.

Planned indexes may include:

- நூற்பா number index;
- இயல் index;
- grammatical-term index;
- example-word index;
- referenced-author/work index;
- cross-reference index to Tolkāppiyam and other Tamil grammar works.

Indexes are derived from verified text and structure. They must link back to stable நூற்பா identifiers wherever possible.
