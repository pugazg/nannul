# English Translation

English translation work belongs here only after the corresponding Tamil units have been source-checked and marked verified.

Translation principles:

- translate from the verified canonical Tamil layer, not from secondary summaries;
- preserve Nannūl's grammatical distinctions and technical vocabulary;
- retain Tamil technical terms where a simple English equivalent would erase a category;
- document interpretive uncertainty instead of silently resolving it;
- keep translation separate from commentary.

Translation status should eventually be tracked by stable நூற்பா identifier.
