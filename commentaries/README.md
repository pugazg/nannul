# Commentaries

This folder is reserved for independently sourced commentarial material on Nannūl.

Each commentary must have its own subfolder and provenance record. Historical commentaries, modern scholarly explanations, and repository-authored notes must never be merged into a single undifferentiated text.

Suggested future pattern:

```text
commentaries/
└── <commentary-id>/
    ├── README.md
    ├── metadata.yml
    └── text/
```

Commentary files should reference canonical நூற்பா identifiers rather than duplicating or silently altering the base text.
