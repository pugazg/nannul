# Data

Machine-readable derived datasets for Nannūl belong here.

Possible future artifacts:

- `nurpa.json` / `nurpa.csv` — one record per numbered நூற்பா;
- structural hierarchy exports;
- grammatical terminology datasets;
- token and word-form indexes;
- relationship data connecting Nannūl rules with Tolkāppiyam or other grammar works.

Every dataset must state its source layer and derivation status. Derived or inferred fields must never be represented as if they were part of the source text.
