# Structure

This folder records the hierarchy of the Nannūl edition independently of the Tamil text files.

`sections.yml` currently captures the section and இயல் boundaries explicitly presented by Project Madurai eText `pmuni0147`.

Future structural files may include:

- one record per நூற்பா;
- parent section / இயல் relationships;
- topic headings appearing inside இயல்கள்;
- cross-references between நூற்பாக்கள்;
- comparison mappings to Tolkāppiyam and later Tamil grammatical works.

Structural metadata is derived data and must not be confused with the source transcription itself.
