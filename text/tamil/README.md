# Canonical Tamil Text

This folder will contain the repository's source-faithful, verified Tamil text derived from declared source material.

Planned organization:

```text
text/tamil/
├── sirappu-payiram.md
├── pothu-payiram/
├── ezhuththathikaram/
└── sollathikaram/
```

Each numbered நூற்பா should retain its source number and stable repository identifier. The text layer must not contain translation, explanatory commentary, modernization, or silent corrections.

The Project Madurai source capture remains under `sources/`; this folder is for the verified canonical representation derived from it.
